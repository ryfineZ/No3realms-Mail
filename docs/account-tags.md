# 邮箱标签编辑说明

状态：已确认
日期：2026-06-17
范围：邮箱列表、邮箱标签接口

## 目标

用户在邮箱列表里可以给已有邮箱打标签，不需要只在新建邮箱时填写。

## 非目标

本次不改变邮箱创建、删除、收信、发信和搜索规则。

## 行为变化

- 邮箱列表更多菜单增加“标签”入口。
- 点击“标签”后打开弹窗，可以编辑当前邮箱的标签。
- 多个标签使用逗号、中文逗号或换行分隔。
- 保存后列表立即显示新标签。
- 普通用户只能编辑自己的邮箱标签。
- 管理员可以编辑列表里所有邮箱的标签。

## 影响范围

新增接口 `PUT /account/setTags`，不改变现有接口地址、参数和返回格式。

## 验证方式

- 邮箱列表更多菜单能看到“标签”。
- 修改标签后，当前邮箱列表项立即显示新标签。
- Worker 测试通过。
- 前端构建通过。
